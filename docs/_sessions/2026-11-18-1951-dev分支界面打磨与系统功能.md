## 2. 关键决策及理由

- **一级图标列固定不滑动**。原作参考图里图标列会滑动，但用户把这个行为报为 bug（“会漂移”），所以固定。除非用户要求，不要改回去。
- **一级图标透明度状态**（经过多轮来回才定下，不要随意改，定义在 `Resources/style.css`）：
  - 没有任何图标被选中时：所有图标 0.88。
  - 聚焦或被选中的图标：橙色，不透明度 1。
  - 有图标被选中时，其余未选中图标：0.5。
  - 有图标被选中时，鼠标悬停的未选中图标：橙色、0.75、无光晕。理由是用户要求“体现出悬停的特别，但不能和激活图标一样”。
- **锁屏用私有函数 `SACLockScreenImmediate`**（login.framework，运行时 `dlopen`/`dlsym`），失败时退回 `pmset displaysleepnow`。理由：macOS 没有公开的立即锁屏 API，这样无需辅助功能权限。
- **重启 / 关机 / 注销走系统自带确认框**（通过 `osascript` 给 loginwindow 发事件），不是强制执行。理由：避免误触丢数据。因此 `build.sh` 生成的 Info.plist 里加了 `NSAppleEventsUsageDescription`；`osascript` 返回 -1743 / -10004 时提示用户去授予“自动化”权限。
- **背景模糊用私有函数 `CGSSetWindowBackgroundBlurRadius`**。理由：能直接给透明窗口设任意模糊半径，`NSVisualEffectView` 做不到这么轻的模糊。
- **鼠标滚轮与触控板的区分**：`wheelDeltaY` 是 120 的整数倍视为滚轮。理由：WKWebView 里没有更可靠的判别方式。
- **子面板的底色画在行上而不是面板上，阴影用 `filter: drop-shadow`**。理由：滚动边缘用遮罩渐隐时，面板底色和 `box-shadow` 的硬边会露出来。
- **设置窗口的拖动用自写的鼠标事件，不用 HTML5 拖放**。理由：需要“之前 / 之后 / 之内”三种落点并自己画指示线。折叠状态只是视图状态（`WeakSet`），不写进配置。
- **用户本机的 `~/.config/sao-menu/config.json` 已替换成新默认配置**。理由：它当时和旧默认配置完全相同，没有用户自定义内容。以后不要再这样覆盖，除非再次确认内容相同或用户要求。

**用户纠正过的理解**

**环境与验证**

- 改完后重启应用：`pkill -x SAOMenu; sleep 1; open build/SAOMenu.app`，需要在沙箱之外执行。
- 界面验证靠无头 Chrome 对临时测试页截图（测试页放在会话临时目录，不在仓库里，新会话需要自己重建）。真实屏幕截图和真实鼠标键盘输入无法模拟，只能让用户实测。
- 做测试页时踩过的坑：
  - `*{transition:none}` 不覆盖伪元素，要加 `*::before,*::after`，否则三角指针的颜色停在过渡中间值。
  - 测试页里遗留的 `!important` 覆盖样式会让新功能（如 `maxRows`）看起来不生效，先查测试页再查代码。
  - 截图要等页面里的异步操作跑完（同步执行，或加 `--virtual-time-budget`）。
- `.icon.error` 之类的规则里用 `background` 简写会重置 `content-box` 裁剪，必须写成 `background: <颜色> content-box`。
- 首次用 SSH 推送报 “Host key verification failed”，原因是 `~/.ssh/known_hosts` 里没有 GitHub 的主机公钥，已补上。
- 包只做了临时签名：在别的 Mac 上首次打开需要右键 → 打开；那台机器上若已有 `~/.config/sao-menu/config.json`，会继续用旧菜单，需删除该文件或在设置里“恢复默认配置”。
